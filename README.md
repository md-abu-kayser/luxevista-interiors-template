A premium, luxury interior design landing page crafted to showcase a modern design studio with elegance, confidence, and conversion-focused UX. LuxeVista is built as a polished static website experience with immersive visuals, strong storytelling, premium branding, and interactive behavior that feels like a high-end agency website.

## Overview

LuxeVista Interiors is a sophisticated digital experience designed for an interior design brand offering premium residential, commercial, hospitality, and office transformation services. The project combines visually rich layouts, layered design aesthetics, motion effects, and conversion-focused sections to help a business present its value with authority.

This project demonstrates how a static site can still feel premium, modern, and production-ready when paired with thoughtful UX, detailed design sections, and carefully implemented interactions.

## Why This Project Stands Out

- Luxury-first visual identity with refined typography and premium spacing
- Fully responsive layout across desktop, tablet, and mobile devices
- Elegant dark/light theme switching for a modern user experience
- Smooth scroll and reveal animations for high-end motion design
- Portfolio filtering for category-based project browsing
- Conversion-focused contact and consultation sections
- Strong storytelling structure for services, portfolio, testimonials, and brand trust

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/md-abu-kayser/luxevista-interiors-template.git
cd luxevista-interiors-template
```

### 2. Open the project

You can either:

- open [index.html](index.html) directly in the browser, or
- run it using a local development server such as Live Server in VS Code

### 3. Customize content

Edit the content inside [index.html](index.html) and the styling in [css/style.css](css/style.css) to personalize branding, text, portfolio items, and colors.

## Customization Guide

### Brand Name and Identity

Update the following brand elements in [index.html](index.html):

- Company name: LuxeVista
- Hero headline and value proposition
- Contact details
- Portfolio project names and descriptions

### Theme and Styling

Adjust the visual direction in [css/style.css](css/style.css) and the Tailwind configuration embedded in the HTML head to match your color palette and brand tone.

### Content Updates

The landing page includes:

- service blocks
- portfolio categories
- testimonial content
- blog storytelling sections
- contact call-to-action sections

All of these are easy to modify directly in the page markup.
